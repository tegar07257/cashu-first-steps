# Cashu in 15 Minutes: Your First Private Digital Cash

A beginner's guide to [Cashu](https://cashu.space), the open-source ecash
protocol for Bitcoin — written for **Nut November 2026** (Cashu builders
hackathon, 1–27 November 2026).

**Read the guide: [GUIDE.md](GUIDE.md)**

What it covers:

1. What Cashu is, and why blind signatures make it private (plus honest limits)
2. How to pick a wallet
3. Getting your first tokens from a mint
4. A zero-risk practice run on a test mint
5. Staying safe: custodial risk, backups, and spotting fake mints

The guide is docs-based: every step was checked against the official Cashu
documentation on 15 November 2026, and it says so openly — including the fact
that it was not tested end-to-end with real sats. No sats were spent writing it.

Author: tegar07 (first-time Cashu contributor).
